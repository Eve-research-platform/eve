# Eve Google Workspace setup checklist

For researchers using the published Eve Google Sheet template:

- [ ] Made my own copy of the Eve launcher Sheet
- [ ] Opened **Eve → Set up / open Eve**
- [ ] Selected **Authorise & prepare Eve**
- [ ] Confirmed `My Drive / Eve` was created
- [ ] Opened the deployment page
- [ ] Created **one Web app** deployment
- [ ] Set **Execute as: Me**
- [ ] Chose the participant access audience required by the research
- [ ] Returned to the Sheet and refreshed deployment status
- [ ] Opened Eve using the secure **Open Eve** button
- [ ] Saved Eve recovery material
- [ ] Passed Eve's final setup checks
- [ ] Ran a disposable study from another browser/device
- [ ] Confirmed the encrypted response appeared in Review

If a new browser does not have researcher access, return to the copied Google Sheet and choose **Eve → Set up / open Eve** again.
